กฎ vibe coding (สร้างเครื่องมือ HTML)

  1. เขียนเจตนาทางดนตรีให้ชัด (ไทยหรืออังกฤษ)
  2. วาง prompt ภาษาอังกฤษที่มีโครงสร้างลงใน LLM → ได้ HTML
  3. บันทึกเป็นไฟล์เดียว → เปิดในเบราว์เซอร์ → ทดสอบ
  4. รายงานบั๊ก/สิ่งที่ต้องการด้วยภาษาคน → prompt รอบถัดไป
  5. เก็บรุ่น เช่น tool-v1.html, tool-v2.html บน Drive
